# CamFinder

أداة لاكتشاف كاميرات المراقبة (Dahua / Hikvision / أي كاميرا IP تدعم ONVIF) على الشبكة
المحلية، موجهة لفنيي تركيب أنظمة المراقبة أثناء العمل عند العميل.

## ما الذي تفعله الأداة؟
- فحص الشبكة المحلية بالكامل عبر اتصال TCP مباشر (connect scan) — بدون ICMP ping
  (لأن أندرويد يمنع raw sockets بدون root).
- فحص البورتات الشائعة للكاميرات: `80` (ويب), `554` (RTSP), `8000` (Hikvision SDK),
  `37777` (Dahua SDK), `8080`, `443`.
- إرسال طلب **ONVIF WS-Discovery** (بروتوكول معياري تعلن فيه الكاميرا عن نفسها طوعًا)
  لتحديد الماركة بدقة أعلى.
- توليد رابط صفحة الويب ورابط RTSP تقريبي جاهزين لكل جهاز مكتشف.
- تصدير تقرير CSV لتوثيق أعمال التركيب.

## ما الذي **لا** تفعله الأداة (مهم)
- **لا تجرب أي اسم مستخدم أو كلمة مرور إطلاقًا** (لا brute force، لا قائمة كلمات افتراضية).
- لا تحاول اختراق أو تجاوز أي حماية على أي جهاز.
- تعمل فقط على الشبكة المحلية التي يتصل بها الجهاز فعليًا (شبكة العميل أثناء التركيب).

## طرق التشغيل

### 1) تطبيق أندرويد (APK) — الطريقة الموصى بها
المشروع يُبنى تلقائيًا كـ APK عبر GitHub Actions في هذا المستودع:
1. اذهب إلى تبويب **Actions** في هذا المستودع.
2. افتح أحدث تشغيل لـ **Build Android APK** (أو شغّله يدويًا عبر *Run workflow*).
3. بعد انتهاء البناء بنجاح، حمّل ملف APK من قسم **Artifacts** أسفل الصفحة.
4. انقل الملف لهاتفك وثبّته (فعّل "السماح بالتثبيت من مصادر غير معروفة" إذا طُلب).

الكود المصدري للتطبيق: `main.py` (واجهة Kivy بسيطة بزر "بدء البحث" وزر "تصدير CSV").
إعدادات البناء: `buildozer.spec`.

### 2) نسخة سطر الأوامر عبر Termux (بديل سريع بدون انتظار بناء APK)
داخل مجلد [`termux_cli/`](./termux_cli):
```bash
pkg update && pkg install python -y
python cam_finder.py
```
راجع التعليقات داخل `termux_cli/cam_finder.py` لتفاصيل أكثر.

## الصلاحيات المطلوبة (أندرويد)
`INTERNET`, `ACCESS_NETWORK_STATE`, `ACCESS_WIFI_STATE`,
`WRITE_EXTERNAL_STORAGE`, `READ_EXTERNAL_STORAGE` (لحفظ تقرير CSV فقط).
لا صلاحية كاميرا، لا جهات اتصال، لا موقع.

## ملاحظات ميدانية
- تأكد إن الهاتف متصل بنفس شبكة الواي فاي الخاصة بالكاميرات.
- بعض الراوترات تفعّل خاصية **Client/AP Isolation** التي تمنع الأجهزة من رؤية بعضها
  على نفس الشبكة — جرّب إيقافها مؤقتًا من إعدادات الراوتر أثناء التركيب إذا لم تظهر نتائج.
- تخمين الماركة من البورتات تقريبي؛ نتيجة ONVIF أدق لأنها تأتي من الكاميرا نفسها.
- لتسجيل الدخول الفعلي، استخدم بيانات العميل الأصلية أو كلمة المرور الافتراضية
  الموثقة رسميًا من الشركة المصنّعة حسب الموديل.
